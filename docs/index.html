02 BEFORE YOU BEGIN

A short setup check

Have these pieces in place before opening the tools. If you are following someone else’s avatar package, they may already be installed for you.

✓

Unity 2022.3 or newer

Open the same Unity project that contains your avatar and clothing assets.

✓

VRChat Avatars 3.10.4 or newer

This is the VRChat avatar package the tools expect to work with.

✓

Modular Avatar 1.18.3 or newer

It builds the menu and toggle pieces into your avatar when you upload it.

✓

An avatar open in the scene

Use the copy of the avatar in Unity’s Hierarchy, not only the saved asset in the Project window.

i

Which avatar should I select? Select the avatar you are currently editing in the scene. Avatar Wardrobe installs onto that scene copy; it does not quietly change the original prefab asset.

03 AVATAR WARDROBE

Add an outfit in four steps

Wardrobe is a local browser window inside your Unity workflow. It searches the clothing already available in your project and helps you make a safe choice.

FIND · CHECK · ADD
01

Select the avatar in the Hierarchy

Click the avatar instance in the scene. If you click a clothing item under it, the tool can follow that selection, but selecting the avatar itself is the clearest place to start.

Hierarchy→Your avatar instance
02

Open Avatar Wardrobe

From Unity’s top menu, choose Tools → Avatar Wardrobe. Check the Install target field, then click Open Wardrobe. Keep the small Unity window open while you browse.

Tools→Avatar Wardrobe→Open Wardrobe
03

Search and check the outfit

Use the search box for an outfit name, color variant, or folder path. Narrow the list with Compatible, Installed, or a category such as Outfits. Open a card to review compatibility, parts, materials, and performance details.

✓ Compatible? Untested! Not compatible
04

Click “Add to Avatar”

Choose the version you want, then click Add to Avatar. Leave Create toggles checked if you want Wardrobe to make controls automatically. The new outfit is added to the selected scene avatar and becomes the default outfit. Its main menu control is labeled Wear This Outfit.

!

Use Advanced install carefully. It allows an outfit marked as incompatible to be added anyway. Try a compatible option first.

What do “Index changes” and “Rebuild” mean?

Wardrobe keeps a searchable list of the prefab assets in your project. Index changes updates that list quickly after you add or change clothing. Rebuild scans everything again and is useful when a result is missing or the list seems stale. You do not need to run either command every time you open the tool.

04 AVATAR OUTFIT TOGGLES

Turn clothing into menu buttons

Use this when an outfit is already in your scene, or when you want to regenerate its controls. You do not need to hand-write animations.

SELECT · GENERATE · TEST
SELECT IN THE HIERARCHY
⌄ My Avatar
⌄ Body
◇ Casual Outfit ← select this
◇ Jacket
◇ Shoes

Select the top-level outfit object. You can select more than one outfit if they are under the same avatar.

1

Pick the outfit root

Click the large parent object for the outfit, not the avatar root and not every individual mesh piece.

2

Create or update the toggles

Choose Tools → Avatar Outfit Toggles → Create or Update Outfit Toggles. You can also right-click the selection in the Hierarchy and open Avatar Outfit Toggles.

3

Try the menu in VRChat

The tool creates a submenu with a control for the outfit and its renderable parts. Build/upload the avatar, then test the menu in VRChat.

⌘

These commands are optional. Start with Create or Update Outfit Toggles.

i

Apple Intelligence is optional. It needs macOS 26+, an Apple Silicon Mac, and Apple Intelligence enabled. Wardrobe and ordinary toggle generation work without it.

05 WHAT GETS CREATED

What should I see afterwards?

The tool does a little setup for you, but the result is meant to feel simple when you use it.

◈

A submenu

A folder-like menu is added to the avatar’s expression menu. With one outfit it is named after that outfit; with multiple outfits it is named Outfits.

◉

One control per part

Renderable outfit parts receive toggles, so a jacket, skirt, shoes, or accessory can be controlled separately when the hierarchy supports it.

↶

A safe editing path

Wardrobe keeps installed outfits visible while you edit. The outfit switches through the menu when the avatar is running, and Unity Undo can restore changes.

BEFORE YOU UPLOAD

A quick confidence check

  • ✓ The avatar in the scene is the one you intended to edit.
  • ✓ You can find the generated submenu in the avatar hierarchy.
  • ✓ You have tested the outfit on and off in the VRChat menu.
  • ✓ You saved the Unity project before building the avatar.
06 FIX COMMON ISSUES

If something looks wrong

Start with the symptom that matches what you see. Most problems are a selection or indexing issue.

?An outfit is missing from the listRefresh the Wardrobe catalog⌄

Click Index changes in Wardrobe. If it is still missing, use Rebuild to scan the project again. Items with no renderable preview may be hidden; turn on the option to show no-preview items if you want to inspect them.

!“Add to Avatar” does not workCheck the install target⌄

Make sure the Avatar Wardrobe window points to a scene avatar instance, not a prefab asset in the Project window. If the outfit is marked incompatible, choose a compatible variant or deliberately enable Advanced install.

↗The toggle command is greyed out or shows an errorCheck your selection⌄

Select one or more outfit roots below the avatar root. All selected objects must belong to the same avatar and need a common parent. Do not select only the avatar itself. If you selected a parent and its child, select just the parent.

◌The outfit looks visible in Unity when I expected it to hideThis is usually expected⌄

Wardrobe intentionally keeps installed outfits visible while you edit the avatar. The generated Wardrobe menu controls which outfit is active when the avatar is running in VRChat.

✦Apple Intelligence options are unavailableThe core tools still work⌄

Name cleaning and toggle clustering are optional helpers. They require macOS 26+, Apple Silicon, and Apple Intelligence enabled. You can rename or organize controls yourself and continue using the regular commands.

07 SMALL GLOSSARY

A few words in plain English

Avatar instance

The copy of your avatar placed in the current Unity scene. This is the version you edit.

Outfit root

The top-level object that holds a complete outfit or accessory group in the Hierarchy.

Toggle

A menu control that turns an avatar object on or off.

Submenu

A folder-like menu that opens to show more controls.

Prefab

A saved, reusable Unity asset. Wardrobe installs onto a scene avatar rather than changing this saved asset directly.

Compatibility

Wardrobe’s best estimate of whether an outfit matches the avatar it was made for.

✦Avatar Wardrobe

Made for calmer avatar editing. When in doubt, select the scene avatar, refresh the index, and use Undo.
